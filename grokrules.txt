6. Parser & Module Signature Discovery Rules (MANDATORY – Learned from 2026-04-08 Debugging)

Before generating or modifying ANY code that calls functions from other modules (especially cad/parser.py:load_step, classify_faces, etc.):

   Use safe extraction:
   occ_shape = parser_result.get("shape") or parser_result.get("occ_shape") or parser_result.get("main_shape")
   If None, raise clear ValueError with list(parser_result.keys())

   Default signature: load_step(step_file_path: str) only.

   - First reproduce the exact call signature and return type using smallest STEP file + LOG_LEVEL=DEBUG
   - Document the discovered signature/return type in docs/architecture_decisions.md as ADR-YYYY-MM-DD-N
   - Use safe dict access or getattr with fallback
   - Add regression test that asserts the exact return structure

4. All OCC-related fixes (pythonocc-core 7.9.3) MUST:
   - Use only: topexp_MapShapesAndAncestors + TopTools_IndexedDataMapOfShapeListOfShape

   - Use ONLY string dot-notation: OmegaConf.update(cfg, "section.key", value, merge=True)
